# Dynamic path identity compatibility shard

This shard covers the bounded dynamic path form `path(.[] | .)`. The
right-hand identity filter must preserve the paths generated by the wildcard
iterator, including each array index and a static object prefix.

The jq 1.8.1 path corpus exercises generator-shaped path filters, including
`path(.[] | select(.>3))`, at `upstream/jq/tests/jq.test:1101-1108`. This
implementation deliberately handles the identity continuation as the first
small slice; predicate-bearing continuations remain pending the general
resumable filter contract.
