# Design decisions

Use one Markdown file per accepted cross-workstream decision. Name it
`NNNN-short-title.md`, starting with `0001`.

Record:

- status and date;
- jq behavior and cited evidence;
- chosen design;
- rejected alternatives;
- affected packages and public contracts;
- ownership and lifetime implications;
- compatibility tests that demonstrate the decision;
- required adversarial-review lanes.

Copy `0000-template.md` when proposing a decision. A proposal does not become a
shared contract until the coordinator accepts it.
